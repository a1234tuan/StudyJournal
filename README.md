# StudyJournal / 学习日志

本地优先的个人学习应用，把学习记录、间隔复习和 AI 辅助训练连接起来。支持 Windows、Android 和 Web。

[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/a1234tuan/StudyJournal)](https://github.com/a1234tuan/StudyJournal/releases/latest)

**记录学过的内容，在合适的时间回忆，再针对真正的薄弱点练习。**

学习日志适合长期自学、备考和课程复盘。你可以先保留完整的学习过程，不必一开始就把笔记拆成闪卡；需要强化记忆时，再加入复习或使用学习助教。基础记录与复习无需登录，也不依赖 AI 服务。

## 下载与安装

前往 [GitHub Releases](https://github.com/a1234tuan/StudyJournal/releases) 选择发布版本，并查看该版本的安装说明与已知限制：

- **Windows**：下载安装程序，安装后从桌面或开始菜单打开，无需单独运行服务器。
- **Android**：下载 APK，在设备上安装。
- **Web**：支持从源码运行或自行部署，步骤见本文“从源码运行”。

安装包、版本号和校验信息以对应发布页为准。Windows 安装包未使用商业代码签名证书，系统可能显示安全提示；请核对下载来源。

**升级、卸载或换设备前，请先导出完整备份。** 不要通过卸载重装解决数据问题，以免丢失本地记录。

## 你可以用它做什么

### 记录与整理

- 按日期、学科和标签整理日志，使用搜索、收藏和回收站管理资料。
- 在同一条日志中保存文字、图片、录音、附件、公式和代码块。
- 使用任务列表、折叠块、结构图、对照表和便签板组织复杂内容。
- 识别图片中的文字，让 OCR 结果参与搜索和 AI 上下文。
- 在录音资料库集中回听日志中的音频，支持倍速与循环播放。

### 间隔复习

- **轻回看**：适合长日志、课程复盘和资料型笔记，以回顾理解为主。
- **记忆卡**：适合需要牢牢记住的内容，使用 FSRS 间隔调度。
- 根据本次回忆表现评分，安排下一次复习；应用未退出时，切换页面后仍可撤回评分。
- 在只读复习正文上做笔迹、高亮和文字批注，不改动原始日志。

### AI 辅助学习

- **AI 问答**：围绕自己的日志追问、解释、自测，梳理理解盲点。
- **学习助教**：从“复习 → 学习助教”进入，结合复习重点与反馈，进行分析、针对性训练和延迟验证。
- **知识播客**：将学习资料整理为适合收听的内容，配合语音合成回听。

AI 为可选能力，需要自行配置模型服务；语音合成等功能还需对应服务配置。模型输出供学习参考，不能替代你的判断，也不会擅自改变整条日志的复习评分。

### 按自己的习惯使用

- 提供“温润阅读”和“清爽现代”两种视觉主题，可独立选择浅色、深色或跟随系统。
- 查看学习记录、复习和学科分布统计。
- 在“更多 → 使用教程”按任务查找记录、复习、AI、资料管理与数据安全说明。

## 第一次使用

1. **记一条日志**：在“今天”新建记录，写下概念、例子、易错点和自己的理解。
2. **加入复习**：保存后，将值得回看的日志加入复习；需要重点训练的内容可标记为复习重点。
3. **先回忆，再看正文**：到期后打开“复习”，先尝试复述，再核对遗漏。
4. **按表现评分**：选择符合本次表现的评分，由系统安排后续复习。
5. **设置备份**：在“更多 → 备份与恢复”导出完整备份；Android 用户还可配置自动备份文件夹。

不必先配置所有扩展服务。完成一条日志和一次复习后，再按需要开启 AI、OCR 或云同步。

## 数据、备份与隐私

### 本地优先

核心学习数据保存在当前设备。Windows、Android 和浏览器中的数据相互独立，不会因为使用同一个应用就自动共享。

浏览器数据按站点地址隔离：不同域名、端口以及 `localhost` 与 `127.0.0.1` 都可能对应不同的本地库。请固定使用同一访问地址；清除站点数据、应用数据或卸载应用可能导致本地内容丢失。

### 备份与换机

- **完整 ZIP 备份**：用于学习数据的迁移、归档与恢复。
- **Android 自动备份文件夹**：资源独立保存，仅补齐新增或缺失资源，保留最近 5 个快照。应用打开后执行备份同步；编辑后如需立即备份，请手动点击“立即同步”。恢复旧仓库需使用“从自动备份文件夹恢复”，绑定文件夹不会自动导入数据。
- **可选云同步**：通过 Google 登录使用 Firebase 同步，在需要时显式触发；它不是实时协同编辑，也不能替代独立备份。

换设备时，先在原设备导出，再在新设备导入并核对记录和附件，确认无误后再清理旧设备。

### 哪些内容不会随备份或同步迁移

- API 密钥、OCR 凭据和设备本地的服务配置需要在新设备上重新配置；自定义 AI 提示词与原始服务响应不随备份或同步迁移。
- 复习批注草稿仅保存在当前设备，不进入日志正文、云同步、备份或导出。评分成功后清除，撤回评分不会恢复旧批注。
- 语音复述的临时会话与本机通话历史不进入云同步或备份。需要长期保留的内容，应主动整理并保存为正式日志。
- 知识播客记录与音频不进入云同步或可移植备份。

### 使用外部服务时

启用 AI、OCR、语音识别或语音合成后，处理所需的文字、图片或音频会发送给你配置的服务商；“凭据仅保存在本机”不代表请求内容不会离开设备。服务可用性、数据保留政策与费用以对应服务商为准，不同平台的能力可能不同。

请勿在公开 Issue、截图或日志中包含密钥、备份文件或真实学习资料。

## 从源码运行

使用 Node.js 24 和 npm。在项目根目录执行：

```powershell
npm ci
npm run dev
```

按终端提示打开开发地址。Windows 用户安装依赖后，也可双击项目根目录的 `启动网页版.cmd`，固定使用 `http://127.0.0.1:5173`。

### 构建

```powershell
# Web 静态产物输出到 dist/
npm run build

# 在本机预览 Web 构建，不是生产部署服务器
npm run preview

# Windows 安装包输出到 release/desktop/
npm run desktop:build

# Android APK，需要 Android SDK、JDK 与本机签名配置
npm run android:build:release
```

原生打包需要对应平台工具链；仓库的 Android 打包脚本通过 PowerShell 运行，并自动构建、同步 Web 资源。不要提交签名文件或服务凭据。

自行部署云同步时，请使用自己的 Firebase、Google OAuth 和 Android 配置，并正确部署与验证仓库中的 Firestore、Storage 安全规则。仅配置客户端参数并不等于完成安全部署。
