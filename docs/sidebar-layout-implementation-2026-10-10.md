# 全局侧栏图标收纳与拖宽实施记录

日期：2026-10-10。基于用户批准的64px图标栏、208px默认展开、192–320px拖宽方案。原已验收改动此前已提交并推送为91867d0，用户已授权提交并推送本轮变更；视觉验收与安装验证仍为独立事项。

## 已实现

- 全局侧栏收纳为64px图标栏，不再由知识库独占折叠状态，也不再完全隐藏导航。主导航与底部分类/设置沿用原SVG图标、顺序、路由回调；选中态、名称和键盘聚焦提示保留。
- 置顶日志收纳为图钉入口，展开浮层保留原来最多5条的置顶列表。支持真实打开日志、Escape关闭并恢复焦点、点击外部关闭、焦点离开关闭和路由切换关闭。同步按钮在图标栏中保持可见，沿用原同步组件和登录逻辑。
- 展开宽度默认208px，持久化范围192–320px。实际显示上限根据布局可用宽度限制，尽量为正文保留720px；921px且有经典滚动条时，192px下限优先，正文可用719px。窗口缩窄不覆盖用户保存宽度，重新放大后恢复。
- 折叠抓手保持4×28px细竖条，位于应用内容可用高度中央；其24×44px点击区放在侧栏外侧，不挡住短窗口内的导航图标。导航图标仍为44×44px点击区。拖动边界8px，中央抓手区域优先处理折叠，不会在拖动结束时触发折叠。
- 边界拖动通过指针捕获与requestAnimationFrame更新，拖动过程不写localStorage；松手提交一次。Escape、pointercancel、失去捕获、窗口失焦、窗口尺寸或页面变化取消未提交拖动并清理状态。
- 边界支持左右键16px步进、Home/End到可用上下限、双击恢复208px。图标栏不参与连续拖宽，展开恢复上次宽度；不会因为拖过阈值自动折叠。
- 偏好单独保存到设备localStorage的study-journal-sidebar-layout-v1；不进入日志、知识库实体、同步或备份。已有本地偏好优先；没有偏好时可一次兼容恢复旧知识库collapsed=true，之后返回历史路由不会覆盖新偏好。存储不可用时布局仍可在本次运行内使用。
- App壳层提供统一--sidebar-width，正文、复习评分栏/批注栏、抓手与拖动边界使用同一个实际宽度。拖动与折叠不重新挂载页面，不触发路由或写学习事实。
- 日志预览索引改为220–260px容器自适应宽度，单栏阈值从860px调整为640px，桌面拖宽不再轻易挤掉列表。知识库保留现有画布/预览最小宽度保护和窄容器底部预览规则，空间确实不足时允许可逆切换，不清除选择或预览，也不新增自动适应画布操作。
- AI聊天保留自己的历史侧栏；编辑/通话等既有沉浸任务、导图全屏继续隐藏全局侧栏及边界工具，退出后恢复本地偏好。920px及以下保持原移动布局，不显示拖宽控件。

- src/styles/sidebar-layout.css：图标栏、抓手/边界、提示和桌面宿主偏移。

- src/styles/content-first.css、desktop-chrome.css：日志预览空间保护、移除旧抓手偏移规则。
