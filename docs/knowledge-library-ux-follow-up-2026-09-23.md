# 知识库第二轮体验修复与验收记录

日期：2026-09-23。状态：源码实施及本地自动化验证完成，等待用户验收；没有安装或覆盖用户应用。

## 本轮改动

- 首页“当前库”直接打开知识库管理，用可点击列表切换库，不再使用当前库原生下拉。支持重命名、显式新建和确认删除本机独立库。拒绝重复名称；已有同名库保留并显示短 ID，不擅自合并或清理用户内容。短 ID 只是容器标识，不是三个必需的功能分区；仅凭名称无法追溯用户现有三个库的创建来源。
- 修复知识库退出动画层仍持有模态窗口／导航监听的问题；退出及卸载时关闭旧窗口。新建专题只在进入创建状态时聚焦，不再随每个字符重新抢焦点；保存后等窗口关闭及忙碌状态结束再导航。账号切换清除旧操作上下文。
- “待整理日志”统一命名为“未加入专题的日志”，仅保留右上角更多菜单中的一个入口，列表标明“当前库未引用”。没有专题时直接显示创建入口；可保留已勾选日志就地创建专题，再加入已有节点或新建收集节点。零选择状态明确显示“选择日志后添加”。
- 日志预览不再增加独占一行的“加入专题”按钮，移入日志右上角更多菜单；所属专题收在可展开列表内。编辑未保存草稿时不增加该跳转入口。
- 移除“知识库与同步”入口及独立同步按钮；首页和备份与恢复原有全局同步会连接默认账号知识库并执行知识同步。普通日志和知识库仍使用各自隔离的同步协议，知识库失败不会伪装成普通日志同步失败。
- 备份与恢复的现有云同步区域增加默认折叠的“知识库同步范围”设置，仅用于解释范围及显式复制本机库，没有第二个同步按钮。本机／访客库不自动上传；确认复制后，副本随下次全局同步上传，原库保留，后续编辑不会自动双向合并。支持继续未完成的复制会话。
- 云权限或配置错误提供可行动提示，不再只让用户反复重试或猜诊断编号。此改动不是生产 Firestore 规则部署。

## 删除、归档与备份边界

- 删除本机库会事务性移除该库的知识表数据，不删除普通日志、复习记录或其他库。取消确认不修改数据；陈旧上下文不能删除新版本。
- 本机知识库回收站可以永久清空：删除已删除条目及其下级节点和引用，保留归档专题及原日志；相关版本、草稿和命令一起清理，不能留下损坏的备份。
- 账号同步库的删除／归档状态参与云同步。暂不支持单方面永久清空云库回收站或永久删除整个账号库，界面解释原因并禁用危险操作，避免其他设备重新带回内容。这不是“已实现云端永久清理”。
- 删除库会增加备份成员代际并触发自动备份脏状态；只有匹配当前范围和成员代际的完整备份确认，才能清除已删除库的旧捕获记录。旧备份异步完成不能吞掉后续变化。
- 没有更改数据库 schema、普通日志同步协议、学习事实或真实用户数据。

## 验收限制

- android-narrow 是浏览器仿真，不等于 Android 真机；Desktop 是 Windows Chrome 浏览器，不等于已安装 Electron 宿主。未声称所有原生偶发卡死已穷尽复现。
- 本轮未安装 APK/EXE、未重新打包安装器、未部署生产云规则、未操作真实账号双设备或付费服务，未重新运行 Firebase Emulator。统一同步的新增行为由隔离单测覆盖，真实云配置和双设备仍需单独验收。
- 本地自动化通过不代表用户已验收；用户当前已安装版本也不会因源码修改自动更新。
