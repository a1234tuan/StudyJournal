# 主题与桌面窗口改造：实施与验收记录

日期：2026-10-10。状态：源码实施及本轮定向自动化门禁通过，待用户视觉/原生手势验收。上一轮工作区布局已经用户验收，本轮没有撤回它。

## 1. 授权与边界

顺序：主题 → 滚动条 → Windows 标题栏 → 一次集中生产构建。保留 208px 导航、65px 工作区页头、日志侧览、稳定 Tab/返回与滚动恢复。没有修改数据库版本、同步实体、复习算法、AI 供应商、品牌、安装路径或用户资料。没有提交、推送、制作/安装 EXE/APK，也没有启动现有用户安装。

## 2. 实际落地

### 主题

- 温润阅读：暖纸背景、暖墨文字和低饱和深绿强调；暗色为暖炭灰。不恢复旧棕色皮肤或旧页面布局。
- 清爽现代：独立的中性背景、导航底色与青绿选中态，不继承阅读侧栏。
- 浅色、深色、跟随系统保持完整配色一致性；修正原先 system-dark 遗漏暖色 accent 变量的问题。
- 日志侧览标题、正文使用既有阅读字体变量；现代主题映射到界面字体。导航、按钮、索引不换字体/尺寸；代码、公式保留自身排版，字号/行距设置不覆盖。
- 更新设置文案与主题缩略示意，不加入示例日志或装饰区。

### 滚动条

- 主题化低对比细滚动条，不全局隐藏；主要内容容器 hover/focus 时增强辨识度。
- 保留根部/日志列表 stable gutter；不在 hover 时改变宽度。
- 横向表格仍可局部滚动；强制高对比度恢复系统自动配色/宽度。

### Windows 窗口

- 仅 Windows 主窗口启用 hidden titleBarStyle + 原生 Window Controls Overlay，保留系统按钮。不使用 frame:false，不自绘窗口控制按钮。
- 36px 拖拽带，为原生按钮预留空间；读取实际主题颜色同步标题栏，响应系统明暗变更。网页、Android、旧版无桥宿主和非 Windows 宿主不增加标题栏。
- 调整标题栏占位，适配日志、知识库、AI、复习、语音、编辑器吸顶栏与主要覆盖层；知识库抓手按剩余内容区居中。
- 导图应用内全屏保留窗口操作带；窗口级全屏移除操作带和占位，退出恢复。
- 保留原有最小化语音暂停、备份 flush 和关闭前备份链。
- 新 IPC 仅接受主窗口主框架；颜色限制六位十六进制，不能修改高度或调用任意窗口方法。保留 contextIsolation、sandbox、webSecurity，nodeIntegration 仍关闭。

核心文件：`src/styles/visual-v2.css`、`src/styles/scrollbars.css`、`src/styles/desktop-chrome.css`、`src/components/DesktopTitleBar.tsx`、`desktop/windowChrome.cjs`。

## 3. 定向测试结果（去重）

### 阶段一

浏览器 7 通过、1 平台跳过：theme-window 主题用例、content-first-visual、ui-v2-stage2。

覆盖两套主题 × 浅/深色；显式明暗与跟随系统一致；常用正文/次要文字、主按钮、导航选中态的被测色对对比度至少 4.5；真实设置点击、持久化、页头几何、桌面/窄屏动作可达。

首轮 3 项失败：新增测试用 getByLabel 精确匹配 select 未找到；旧窄屏测试未先打开已验收的筛选弹层。修正测试定位/交互，仅重跑这 3 项全部通过，没有改变产品逻辑。首轮已通过的截图因测试输出目录重建未全部保留，不能声称所有首轮证据均已存档。

### 阶段二

浏览器 10 通过：滚动条 2、日志 Tab 锚点 2、复习视图 2、统一页头返回 2、多列嵌套表格局部滚动 2。覆盖实际滚动距离、桌面滚轮/PageDown、hover 尺寸不变、高对比度与局部横向滚动。

### 阶段三

定向单测共 18 项通过：窗口桥 6、原生菜单 3、标题栏组件 5、主题持久化 2、设置字号 2。

最初一次 Vitest 因 min/max worker 冲突未执行；补齐 minWorkers 后，新 mock 的 Promise 被框架重置导致异步异常，修正测试初始化/cleanup 后标题栏 5 项无异常通过。不把有 unhandled error 的运行计为绿色。

隔离 Electron 开发态 12 组宿主场景通过。真实发现并修复 Windows 全屏事件时序问题：enter-full-screen 回调内 isFullScreen() 可能仍返回旧值。现在按进入/退出事件发送明确状态，测试明确模拟旧 getter 值。

宿主脚本还修正了首次启动迁移/每日计划提示、创建日志先进入只读而非编辑等测试流程；系统主题检查取消 Playwright 默认浅色模拟。这些属于测试适配，没有靠删除提示或改变产品入口绕过。
