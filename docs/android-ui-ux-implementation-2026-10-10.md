## 同日首页验收后修复

用户反馈首页空状态右侧留白、学科下拉左侧越界和组合按钮视觉高度不一致。本次仅调整 `src/styles/mobile.css`，新增 `e2e/mobile-today-layout.spec.ts`，不改变业务组件、保存逻辑、路由或桌面规则。

- 根因一：`.today-content-grid` 从桌面 Grid 改为纵向 Flex 后仍继承 `align-items: start`，日志列随内容宽度收缩。改为 `stretch`，空状态和记录卡均与内容区域对齐。
- 根因二：310px 下拉面板右对齐到更窄的新建组合按钮。412px 浏览器视口实测左边界为 -61.86px。改为组合按钮左侧锚定、视口内最大宽度，限制高度并允许滚动；长学科自动换行，学科按钮至少44px高。
- 根因三：主按钮保留了旧版浅色外边框，而箭头仅有分隔线，造成目视高度不一致。移除主按钮旧边框，两半使用伸展布局、至少48px高度，兼容字号放大。

本次验证：TodayPage/mobilePresentation 两文件13项单元测试通过；去重7项浏览器用例通过（3个新增移动流程、1个新增桌面首页隔离，以及既有移动首页、放大字号工具页、桌面复习样式隔离）。覆盖320px/1.25倍字号、390px现代暗色、412px温润亮色，空列表/有记录、12个学科及长名称、模板选择→新建→编辑→保存→返回。桌面首页下拉和复习页面移除移动样式前后截图一致。`git diff --check`通过。
