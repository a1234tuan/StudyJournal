# 日志复习导航安全修复（2026-09-27）

## 范围

针对恢复桌面复习侧栏后暴露的未评分评论丢失、批注写入失败后离开、返回早于写入完成的问题。保留桌面加宽布局，不更改安卓布局、评分算法、数据库结构或云同步协议。

## 实现

- 评论及“加入待分析”选择保存在 App 持有的复习运行状态中，以记录、复习轮次和正文版本隔离；评分成功后清理对应草稿，撤销评分恢复对应评论。输入事件先同步捕获文本或勾选值，再更新上层状态。
- 批注按草稿 ID 串行写入。期间发生的新修改继续写入；重新打开草稿前等待此前待写内容。读取完成前禁用新增批注，避免空白初始状态覆盖已保存批注。
- 应用内经 commitNavigation 离开复习页时先执行批注检查。失败留在原页并显示重试按钮，成功后继续导航；正在编辑下拉选项或绘制时要求先完成操作。
- 保存失败保留当前运行实例中的待写草稿；卸载补写捕获异常，避免未处理 Promise。刷新/关闭的 beforeunload 保护只针对当前批注待写或未完成操作。

## 边界

- 未评分评论是当前应用实例的会话草稿，不保证刷新、关闭应用、崩溃后的恢复，不是跨设备同步内容。
- 本次离开阻断接入应用内 commitNavigation；浏览器原生历史 popstate 不走该入口，不能宣称具有相同阻断保证。批注协调器仍在当前实例中保留失败待写内容并协调重新加载。
- 评分成功清除本次批注、正文版本变化使旧批注失效的既有规则不变。
- 自动化在隔离浏览器和测试数据中运行；没有真实用户数据操作、生产部署、APK/EXE 打包安装或 Git 提交。
