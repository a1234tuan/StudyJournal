# 知识库导图与阅读工作区体验实施记录（2026-09-29）

## 范围与边界

本次按用户确认分阶段实施导图快捷输入、方向导航、拖拽吸附预览、日志右侧阅读与知识库导航收纳。只修改前端交互、局部布局和回归测试，不修改数据库 schema、同步协议、日志事实、复习统计或知识库数据归属。没有部署、安装 APK/EXE、提交 Git、访问真实账号或调用付费服务。

## 第一阶段：快捷输入与节点导航

- 画布内选中普通节点后，Enter 在其后新增同级节点，Tab 新增末尾子节点。专题中心是展示根，不生成专题同级节点。
- 新节点以临时布局节点在目标位置出现并立即聚焦名称输入；Enter 保存后恢复选中和焦点，可以继续 Enter/Tab 连续输入。临时布局不写入正式知识节点；保存使用原有命令、草稿与冲突保护。
- 中文输入法组词确认不会误提交；忽略按住按键的重复创建。输入控件、日志阅读区和分支折叠按钮不接管画布快捷键。Shift+Tab 保持普通反向焦点移动。
- 双击节点或已有 F2 入口原位改名。Escape 沿用安全退出草稿流程。
- 上下左右键在可见节点中导航，水平方向优先父子关系；选中节点自动移入可视区域。没有选中节点时保留原来的方向键平移画布行为。
- 只读/保护中/复制中节点禁止创建与拖动，保留浏览选择以及普通 Tab 焦点移动。

主要文件：src/features/knowledgeLibrary/KnowledgeMap.tsx、KnowledgeLibraryPage.tsx、KnowledgeOutline.tsx、presentation.ts。

## 第二阶段：拖拽吸附预览

- 使用原有命中与移动命令，新增父节点连接虚线、吸附端点和目标位置轮廓。
- 节点中部表示成为其子节点；上下边缘表示放到该节点之前/之后。移到自身或后代时显示无效反馈。
- 追加子节点的轮廓放在目标现有子树下方，排除正在移动的分支，避免误画在已有子节点上。
- 轮廓表达目标父级和插入顺序，不承诺落下后的绝对像素位置；正式落下后仍由现有树布局重排。
- 松开鼠标前、取消拖动或按 Escape 均不提交位置写入。

## 第三阶段：日志阅读面板

- 点击节点详情或大纲中的关联日志，在同一工作区展示独立只读日志组件，而非把完整编辑页面嵌入侧栏。复用富文本渲染以保留正文结构，不创建编辑草稿。
- 日志打开时节点详情隐藏但保留挂载。侧栏返回、页面返回和 Escape 优先关闭日志，回到原节点说明；不是直接关闭整个工作区。
- “打开完整日志”进入原完整日志页面；返回先恢复侧栏和阅读滚动位置，再返回原节点说明。浏览器 Back 覆盖完整日志→侧栏→节点说明两级路径。
- 桌面默认宽度 420px，可拖动分隔条调整到 360–560px，也支持分隔条键盘方向键、Home/End。实际宽度受工作区限制，给导图保留至少 320px。
- 屏幕宽度不超过 920px，或工作区宽度小于 720px 时切到底部阅读面板，使用工作区高度的 75%，避免在中等宽度窗口把正文挤成窄条。
- 缺失/删除日志显示不可用说明并禁用完整打开，仍可返回节点说明。正文中的有效日志引用可继续在面板内打开，删除引用不导航。
- 面板宽度、阅读滚动位置和导航收纳属于本地导航状态，不进入知识库同步数据。

主要文件：新增 KnowledgeRecordPane.tsx，KnowledgeDetails.tsx、KnowledgeLibraryPage.tsx、navigation.ts、knowledgeLibrary.css、src/App.tsx。

## 第四阶段：左侧导航收纳

- 知识库首页、专题大纲和导图提供左侧导航收起/展开入口。收起后地图或大纲与阅读面板获得释放的横向空间。
- 收纳仅作用于知识库工作区；完整日志及其他页面沿用原导航布局，返回知识库恢复之前的收纳状态。
- 窄屏已有底部导航，不显示桌面侧栏收纳按钮。

### 测试过程中发现并处理

- 子节点吸附虚框原先覆盖已有子节点，已改为现有子树之后并补充纯函数断言。
- 窄屏收纳按钮曾被通用图标样式覆盖显示，已提高局部选择器优先级。
- 旧知识库浏览测试改为明确先点“打开完整日志”，保留原完整浏览返回断言；知识库入口定位限定当前页面，避免与新增/既有侧栏同名入口混淆。
- 快速创建后立即点击返回的旧测试需等待提交结束，避免在保存中触发操作；不通过放宽产品写入保护解决测试问题。
- 长文测试最初直接改数据库但未更新应用内存快照，已改为启动前注入数据，未修改产品数据刷新边界。
- 早期补丁工具调用未实际落盘的基线测试不作为本次通过证据；验收数据均来自实际修改后的代码。

## 用户验收建议

1. 连续 Enter 新增同级、Tab 新增子级，中文输入后 Enter 保存；确认光标与选中节点符合预期。
2. 四方向选择与双击改名；折叠分支和查看全貌后继续使用快捷键。
3. 拖到节点中部/上边缘/下边缘，观察预览父级和顺序，再松开核对实际结果。
4. 打开关联日志，拖动宽度，进入完整日志并连续返回，确认先回日志侧栏再回节点说明。
5. 收起左导航后同时使用导图与日志面板，切换其他页面再返回，确认布局互不干扰。

自动化浏览器与触摸模拟不是 Windows 安装版或 Android 真机验收；本次未覆盖用户已安装的应用，正式打包/安装仍需单独授权。
