- [x] ZIP、流式/native backup、知识导出和记录转移不包含语音本机数据或凭据。
- [x] 普通重启恢复为暂停，不自动重新打开麦克风。

- [ ] DeepSeek：首 token、长会话、结构化评估、限流、超时与取消。

- [ ] 核对 Provider 数据保留、地域和内容安全条款，并确保外发清单准确。

## 真机门槛

- [ ] 安静、道路背景、撞击、喷嚏和多人背景讲话；记录自动模式误触发率，长按/点击模式可兜底。
- [ ] 手机扬声器回声、有线耳机、蓝牙耳机和音频设备切换。
- [ ] 锁屏、切后台、系统返回、来电、网络切换和弱网恢复。
- [ ] 30 分钟以上长会话、容量上限、配额用尽、存储压力和崩溃恢复。
- [ ] Android 物理设备上的麦克风权限、输入法、音频焦点和前台服务行为。

以上真实 Provider 与真机项目未全部通过前，只能发布 Mock/受限预览能力，不得宣称真实语音链路已经量产验收。已完成的隔离原型视觉验收不能替代真实音频链路验收。
