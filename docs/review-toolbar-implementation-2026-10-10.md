# 复习顶部控件收敛实施报告

日期：2026-10-10。范围：用户批准的复习顶部布局与操作入口整理，不改动上一轮已验收的主题、桌面标题栏或其他工作区布局。

## 落地结果

- 普通复习页头保留轻量“复习”标识，四个视图入口并入同一行；不再单独占用正文上方的一整行。窄屏隐藏重复的可视标题，但保留语义标题和四个入口。
- 会话工具栏统一承载返回来源、当前序号、已完成数量、细进度条、看板、批注和更多。桌面一行，窄屏将进度放到第二行；保持控件至少44px高，不以压缩点击范围换空间。
- 页头常驻编辑删除；更多菜单保留唯一“编辑原日志”，显示E快捷键提示。沿用原编辑回调，实际编辑、保存并返回同一卡片的浏览器验证通过，未产生评分。
- 看板移到日志复习会话局部，沿用原浮窗与范围选择流程。卡片库和学习助教不显示无关的会话工具；空队列仍保留看板、刷新及撤回入口，避免最后一条评分后无法撤回。
- 批注使用图标加文字，沿用原portal、开启状态、加载禁用与离开保护。已安排复习也使用相同局部入口，不再另悬浮一个模糊铅笔图标。
- 更多菜单保留撤回、刷新、编辑原日志、AI问答、语音复述当前卡片；移除这里的学习统计入口，统计功能及其他工作区入口不变。
- 返回卡片库、返回看板、已安排轮次返回继续调用原有退出处理，不改变调度、评分、复习检查点、批注数据、同步或备份语义。

## 变更位置

- src/pages/ReviewPage.tsx：页头与会话工具栏、普通/已安排共用菜单、空队列入口。
- src/features/reviewAnnotations/ReviewAnnotationSurface.tsx：嵌入式批注按钮文字；非嵌入式入口保持原表现。
- src/styles/workspace-layout.css：仅作用于复习工作区的响应式布局和按钮样式。
- src/pages/ReviewPage.test.tsx：新增入口归属、唯一编辑、非会话视图和空队列回归断言，更新统计入口的旧断言。
- e2e/review-session-toolbar.spec.ts：新增尺寸、主题、大字号、工具栏位置、交互与保存返回验收。
- e2e/arranged-review.spec.ts：已有编辑流程断言改为“编辑原日志”。
- e2e/review-workspace.spec.ts：居中断言以实际布局视口为基准，不把滚动条预留区算进内容画布。

## 定向验证

1. 单测：ReviewPage 53项、ReviewAnnotationSurface 9项，共62项通过。首次运行的一项失败来自原测试仍要求已移除的菜单统计入口；按新契约更新后通过，没有改动业务实现来迎合测试。
2. 浏览器：去重22项通过，6项为原测试明确限定平台的跳过。覆盖普通复习与已安排流程、范围选择、看板打开/关闭/返回与焦点恢复、语音入口返回、E快捷键、更多菜单编辑及保存返回、批注加载/保存/失败阻断/未完成选项保护、工作区切换稳定性。
3. 布局：新增用例覆盖1440、1024、921、600、390、320px，结合温润阅读/清爽现代、明暗模式和320px下1.25字号；验证无横向溢出、按钮无重叠、点击高度、菜单不越界、Tab切换位置稳定。人工查看1440px浅色与320px深色大字号截图，顶部控件层次和正文空间正常。
4. 首批浏览器结果为21通过、1失败、6跳过。失败是旧看板断言相对1440px窗口计算中心，而稳定滚动条预留10px后实际布局宽度为1430px，导致5px差异。实测看板x=255、宽920，中心715，恰好对齐布局中心；不需要改生产布局。修正测量基准后，仅复测相关4项，全部通过，未重复跑整批。
5. 最终TypeScript构建图检查通过；测试新增时一个Testing Library不支持的exact选项已删除，未改查询匹配语义。改动文件git diff --check通过。
