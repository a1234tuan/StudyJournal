# 今日计划：提前制定与到期显示（2026-09-28）

## 授权与范围

用户在本轮确认接入方案后明确要求直接实施。这是既有今日计划的定向扩展：选择今天或未来的特定日期制定计划，到目标日期再开放计划日志入口。它不扩展到重复计划、批量排期、自动提醒、AI 排期或全局日志日期限制；不改变复习、FSRS、评分及知识库语义。

## 用户行为

- 首页仍从“今日计划”进入，默认今天。计划页保留“按日 / 历史”；日期字段位于添加计划卡片首行、学科之前，不再设置外部工具栏或今天/明天快捷按钮。
- 日期字段默认显示“今天”，其他日期显示月日，跨年显示年份；键盘聚焦时使用原生日期编辑。创建表单、列表标题均对应同一个选中日期。新计划只能选择今天或未来的有效本地日历日期。
- 未来计划在选定日期的制定界面可查看、删除，标记“待开始”；不能从计划入口提前生成日志。它不出现在今天的待写入列表或历史分组中。
- 切换日期保留输入的标题及学科；成功添加后只清空标题，保留日期和学科。选择今天恢复自动跟随本地日期，无需“回到今天”按钮。
- 未来日期不显示“已安排”顶部计数、同步备份说明或“到指定日期才开放写日志”的重复句子；目标日期由列表标题表达，执行状态由条目状态表达。详细规则仅保留在使用说明。
- 目标日期到来后显示为当天计划，允许写日志。到期只改变呈现，不自动创建日志、草稿、复习记录或云端变更。
- 过去未完成的计划保留在历史，可补写；补写日志仍归属原计划日期，不把历史未完成计划自动搬到今天。
- 明确选择的日期在进入日志再返回、切换历史视图时保持；今天模式随本地日期前进。退出计划页后再次从首页进入默认今天。
- 已存在的普通日志，包括旧版本创建的未来日期日志，不做全局隐藏、删除或日期改写。

## 数据、同步与备份

继续使用 `DailyPlan.date`。保存未来计划只写入计划实体，沿用计划变更标记、自动备份 dirty 标记及现有 `daily-plan` 云实体导出链路。

未来计划立即具备云同步与完整数据备份资格，不必等到目标日期；是否实际上传或形成有效备份，仍取决于对应操作启用并成功。其他设备收到计划后按自己的本地日历日期判断显示及可执行性。跨时区设备可能在不同绝对时刻进入同一日历日，这是沿用本地日期语义，而非服务器定时发布。

`planDate` 仅属于导航状态，不加入同步实体或备份内容。没有数据库 schema、同步协议、云规则、包标识或版本升级。

旧版客户端虽能接收同一计划实体，但没有这次新增的未来日期显示/执行限制，仍可能在其历史页展示并打开未来计划。跨端一致体验需要各端升级到包含本改动的版本；本次不会删除旧版已产生的真实日志。

## 实现入口

- `src/pages/DailyPlanPage.tsx`：日期选择、未来状态、按选中日期展示、过滤历史、禁用提前写入。
- `src/hooks/useAppData.ts`：创建日期校验；打开计划前重新读取最新计划，检查存在性、删除状态及到期日期，再复用或创建日志。备份与同步继续使用既有保存链路。
- `src/hooks/useLocalToday.ts`：本地零点刷新；窗口焦点、Web 可见状态和 Capacitor 前台事件校验日期；最长一分钟重检时钟变化。卸载时清除计时器与监听器。
- `src/lib/tabNavigation.ts`、`src/lib/webNavigationHistory.ts`、`src/App.tsx`：保存/恢复选中日期，非法历史快照日期回退到今天模式，不新增导航深度。
- `src/lib/planStats.ts`：学科完成统计与现有近 7/30 天、连续完成口径一致，排除未来日期。
- `src/pages/UsageGuidePage.tsx`：同步更新使用说明。

## 同日 UX 精简

用户指出页面级日期工具栏和说明文字增加理解成本后，本次将日期变为创建卡片的单一中性表单字段，删除额外按钮及两处冗余说明；未来状态改为“待开始”，去掉未来计数，增加日期列表标题。跨零点停留在过去日期时，卡片内仍保留日期字段以便重新选择，原日期已有计划仍可补写。

这次优化不修改存储、云同步、备份、到期限制或导航契约。日期选回今天时将导航日期恢复为跟随今天模式，延续此前“回到今天”的行为。

同步/备份测试使用真实本地适配器与隔离 IndexedDB，校验普通快照、流式快照、云实体导出/重组/恢复均保留未来计划，且不产生日志、草稿、复习状态。它不是生产账号同步或物理备份目的地验收。

浏览器用例使用真实浏览器及隔离 IndexedDB，覆盖未来计划创建、重启后保留、到期前隔离、到期解锁并保存日志、返回保留日期、跨年恢复与历史保留。
