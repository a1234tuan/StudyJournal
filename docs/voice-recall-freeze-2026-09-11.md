# 2026-09-11 语音复述阶段冻结

## 冻结结论

本阶段代码与生产资源冻结。Android 真机已验证自动听说半双工主链可连续运行多轮：

> 自动监听 → 用户讲话 → ASR → LLM → TTS → 播放 → 再次监听

实机确认了自动输入、自动提交、AI 回复播放和下一轮监听。该结论不扩展为全部语音交互已发布验收。

## 已完成

- 自动听说半双工 Android 真机多轮验证。
- ASR 延迟达到可接受范围。
- 自动 LLM 提交、TTS 播放和播放后重新监听。
- 自动模式第三轮 ASR 偶发卡住的清理竞态修复。
- 语音阶段确定性测试、生产构建和 Android Java 编译通过。

## 未实现

- barge-in / 全双工插话。
- SiliconFlow 实时 ASR。
- 豆包 TTS。
- PCM/Opus 无缝增量播放。

## 尚未真机验收

- 按住讲话。
- 点击录音。
- 通话界面的静音与字幕键盘输入。
- 结束面板中的暂停并离开、继续通话和结束通话。
- 保存到本机日志。
- 整理为日志。
- 不保留并返回。
- 蓝牙/扬声器切换、系统音乐、后台、系统返回、网络切换和弱网恢复。

## 发布边界

本冻结不是完整生产发布签字。后续工作只能从未验收清单中逐项推进，不应在本阶段混入新的 Provider 或音频协议。真实 Provider 测试仍须使用轮换凭据并单独批准调用次数与费用额度。
