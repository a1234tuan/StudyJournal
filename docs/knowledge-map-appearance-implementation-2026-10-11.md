# 知识库导图样式与结构实施记录（2026-10-11）

## 授权与范围

用户确认节点高亮、整节点标题颜色/加粗、编辑样式侧栏，以及双向/四向/单向布局和曲线/直线/折线接入方案并授权实施。本轮是知识库表现层及其必要持久化扩展，不扩大为自由白板、跨分支语义关系或标题内局部富文本，不改变日志、复习、FSRS、Coach、账号归属或数据库表结构。

上一轮未提交的日志图标直达预览、导图留白、单步撤回和空标题退格删除保留。未提交、推送、安装或调用真实账号。

## 已实现

- 节点：默认及黄/绿/蓝/紫/橙背景与文字颜色、加粗、恢复默认。颜色通过主题文本/表面色混合映射，选中轮廓不覆盖高亮。
- 桌面右侧样式面板与日志预览/节点说明互斥。重命名自动显示样式面板，也可单独点击调色板入口。
- Android 使用工作区内的底部面板；不移除全局导航、不套用桌面右侧窄栏。实际软键盘/真机手感仍需物理设备验收。
- 重命名中的标题与样式在本地同一事务提交；已有节点草稿记录样式及其原始基线。明确取消丢弃该草稿；离开时维持原有保留草稿行为。
- Ctrl/Cmd+Z 撤回最近一次标题/位置/样式/结构修改；同一次标题加样式的本地撤回也是事务性的。不是无限历史栈；不改变文字输入框自己的撤回。
- 双向导图保持默认；新增单向逻辑图和上下左右四向发散，非任意角度径向图。父子关系不变，标题不旋转。
- 线型与结构独立；曲线、直线、直角折线。连线锚点、四向拖拽提示和折叠按钮方向适配。
- 新建专题可以选择结构和线型，确认后进入导图；旧专题缺少配置时原样读取，不自动补写默认值。
- 样式和结构可复制到新库、备份并恢复，冲突面板显示可读样式并支持选择候选。

1. 节点新增可选原子单元 style，专题新增可选原子单元 map。均为枚举白名单对象；不允许 CSS、HTML 或任意未知属性。
2. 旧实体的必需字段校验保留。无样式库继续生成 v1 云包；首次正式样式/结构配置生成 v2 云包。新客户端读取 v1/v2。
3. 注册/default registry 保持 v1；升级发生在具体库的提交头。服务端规则禁止 v2 提交头降级回 v1，防止旧客户端写回丢失配置。
4. 旧客户端不支持 v2 库。参与同步的客户端必须统一升级。将节点恢复默认不会降级已升级的库。
5. 带样式的知识备份使用 envelope v2；无样式仍为 v1。整包容器仍为 v7。旧客户端不能恢复带样式的新备份；拒绝而非静默丢失。
6. 本地 IndexedDB schema、普通日志同步协议、所有者隔离和数据路径不变。标题和样式是两个正式原子单元，本地批量提交/撤回原子化；跨端同步仍按既有连续命令推进，不宣称两个云命令原子提交。
7. **生产规则已在用户另行授权后于 2026-10-11 15:51:56（北京时间）部署，并读回核验一致。** 原先“规则未部署”的阻塞已解除；仍需电脑、手机客户端统一升级和真实两端同步验收。详见 docs/knowledge-map-appearance-production-rules-2026-10-11.md。

## 验收建议

桌面：节点双击编辑 → 高亮/文字/加粗 → 保存 → Ctrl+Z；单独改样式；切换三种结构与线型；日志图标仍一步预览；重启后配置保留。

Android：样式从底部显示，320/390 窄屏无横向溢出；长按移动、缩放和面板滚动互不冲突。真机上额外检查软键盘、输入法和确认按钮触达。

部署：生产规则与多端升级是独立发布门禁，不能以截图或本地浏览器通过替代。
