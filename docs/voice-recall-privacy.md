# 语音主动回忆隐私说明

## 外发数据

开始通话前，应用会按 Provider 分别展示并要求确认以下范围：

- ASR：麦克风音频，用于生成转写。
- LLM：用户选择的日志片段、会话所需的有限上下文，以及用户确认后的转写，用于提问和反馈。
- TTS：教师回复文本，用于合成语音。

日志、附件识别文本和转写都按不可信学习内容处理，不能覆盖系统规则、索取凭据或触发工具。第一版不向 LLM 提供工具调用能力。

具体 Provider 可能按照其服务条款记录请求。使用真实 Provider 前，应在供应商控制台核对数据保留、地域、内容安全和计费政策；本机费用显示仅为估算，账单以 Provider 为准。

外发清单由当前解析出的链路生成，而不是模板里的静态名称：确认页显示的是本次实际调用的 ASR、LLM 与 TTS（含模型名）。只要任一环节缺少凭据或当前平台不支持直连，通话就不会开始，也不会有任何数据离开设备。Web 端不提供真实语音链路——实测 ASR 需要自定义 `Authorization` 头（浏览器 WebSocket 不支持），Fish Audio 的预检响应不含跨域许可。

## 本机数据

- 原始 PCM 帧、ASR partial 和 TTS 分片仅用于当前处理，不进入正式学习事实。
- 未完成会话和轮次以本机临时检查点保存，App 重启后只能从暂停状态恢复。
- 用户主动保存的摘要进入“本机通话历史”，但不进入云同步或完整备份。
- API Key、自定义 endpoint、模型和音色覆盖只保存在当前设备，不进入云同步、ZIP/流式/native backup、知识导出或记录转移。

完整备份恢复会清除临时会话和轮次，同时保留恢复前已有的本机通话历史。卸载、清除应用数据和换机均不承诺保留这些数据；需要跨设备保存时，应先整理为正式日志。

## 正式学习事实

自由主题和普通资料练习不会自动评分、修改 FSRS 或写入 Coach 正式事实。Coach 语音回答只有在用户校对并确认后，才沿既有事务写入当前题目的唯一 `answerText`。语音来源不会形成第二套答案事实。
