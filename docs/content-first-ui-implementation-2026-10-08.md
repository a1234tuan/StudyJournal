## 1. 采用的修正策略

不是全量回退，也不是继续堆叠补丁。保留已验证的日志侧览、来源返回、浏览器历史与滚动恢复；重写偏离样稿的展示层。此前“保守沿用旧样式”不等于“忠实落地样稿”，这一点已纠正。

- **V2 是视觉基线**：纸白底、灰绿导航、深绿主动作、紧凑页栏、日志内容主区与辅助区的主次关系。
- **R2 是生产行为约束**：真实按钮和数据、窄屏适配、只读侧览、编辑离开保护、既有同步与复习语义。二者不是互相替代。
- 没有复制样稿演示数据、绿色演示顶栏、示例说明、假同步状态、无对应能力的按钮，也没有增加逐篇日志虚线。
- 不修改数据库、云协议、备份服务、FSRS、AI 范围或正式数据。浏览器用例中的业务事实前后对比不变；桌面仅编辑隔离测试日志。

## 2. 最终落地

### 配色、导航和首页

默认浅色准确采用 V2 的背景 #f7f7f2、纸面 #fffefa、主色 #356047、侧栏 #f0f2e9，导航宽 208px。保留原阅读/现代主题选项及浅色/深色/跟随系统设置；深色使用对应可读前景色，不强制用户回到默认设置。

首页保持左侧新建与独立学科/模板展开入口，右侧今日计划、收藏夹。正文为日志列表主栏与复习/目标日期辅助栏，窄屏纵向排列。顶部保留小号页面身份、日期、搜索和真实同步入口。不再保留大标题宣传式页头。

今日日志标题编辑仍存在，收纳到轻量展开项。日志操作通过可点击、可键盘操作的三点入口展开，不依赖 hover；AI 仍按日期传参，收藏/加入复习复用原回调。知识库入口选中时不再同时点亮“更多”。

### 日志资料库

- 视图切换、学科选择、知识库与搜索使用紧凑工具栏；排序仍是日期优先，不虚构“最近更新”排序。
- 普通全部日志支持列表旁只读侧览；索引宽 260px、约 72px 起的条目，隐藏重复摘要和标签。正文面板获得剩余宽度。
- 1440×980 的实测：索引 260px、阅读面板 924px、标题区顶部距面板顶 60px；普通段落最大行宽 720px。代码/表格等继续使用富文本阅读器。
- 可用工作区不超过 859px 时切为单阅读区，显式“返回列表”；这不是强制全屏，也不强行收起桌面全局导航。
- 列表 → 侧览 → 完整页/编辑 → 返回侧览 → 返回列表保留筛选、加载数量、选中项和阅读位置。侧览间切换替换历史，首次打开推入历史。
- 搜索、日期/学科、收藏等原入口维持原完整页链路，不把不同来源强行统一。来源删除/失效明确显示不可用并禁用完整打开。

### 知识库

保留真实导图布局、节点编辑/拖拽、数量入口和应用内全屏。标题与返回入口收敛；导航折叠放在侧栏边界，不挤占页头。宽工作区未设置侧窗宽度时默认 480px，其他默认 420px；用户已保存的 360–560px 宽度优先。

关联日志继续原地侧览，完整打开是显式动作，返回保留节点、缩放和侧览位置。测试证明短标题节点在 0/1/10/100/1000 引用时仍有紧凑尺寸；没有证据支持再改底层布局，因此没有重写几何或新增虚线。
