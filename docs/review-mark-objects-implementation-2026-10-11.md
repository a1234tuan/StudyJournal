# 公式与代码永久复习印记：实施记录

日期：2026-10-11。用户授权补齐此前仅支持纯文字的永久复习印记；这是既有印记功能的定向扩展，不改变日志或评分调度。

## 落地范围与操作

- 普通日志间隔复习中打开「永久复习印记」，点击行内公式或公式块，选择样式后「标记选中内容」。整块公式含标题按整体标记，不拆分公式内部符号。
- 代码可以拖选片段、多行，或点击代码块进行整块标记。拖选结束不会被点击处理覆盖成整块。
- 「选择公式或代码块」列表提供键盘和手机上的整对象选择入口；选项显示公式源码或代码摘要，不另建内容副本。
- 同一内容块内的文字与公式可以一起选择；选中部分公式时按整个公式处理。仍支持四种颜色、高亮/下划线/框选/段落边标、修改、擦除、撤销、重新定位和冲突确认。
- 保持复习专用覆盖层：不修改日志 HTML，不出现在完整日志编辑/预览中，不进入安排复习、AI 上下文或调度评分事实。
- 本轮不支持图片、自由手绘、跨顶层内容块选择、公式内部局部符号。含不支持节点的混合内容块会明确拒绝，不静默保存不可靠位置。

## 定位与显示约束

原有文字锚点保持原结构和读取逻辑。新锚点增加可选 structured 字段，用语义块序列表示文字、公式源码和换行；公式是原子单位，不把 KaTeX 生成的重复文本或辅助 DOM 当作内容。

代码定位不依赖语法高亮 span 的分割；保留缩进和换行。重放要求语义块源码匹配，重复块用前后相邻块上下文消歧，仍重复则拒绝定位。源码变化时显示待重新定位，不按序号或相似文本猜测；同段其他文字变化也可能需要人工重新定位。

绘制在布局、公式异步渲染、字体加载和滚动后重新测量。代码片段印记裁剪在横向滚动容器可视范围内，整代码块标记覆盖可视块边框，不向相邻内容泄漏。打开工具时才启用对象点击选择；关闭后保持原阅读交互。

## 同步与备份

- 数据库保持 schema29，不加表、不改旧事件；仍使用不可变因果事件，擦除不抹掉历史，跨端并发修改/擦除保留原冲突处理。
- 普通云同步协议由 3 升至 4；新版在原有事务锁内接纳并升级 2/3。旧协议3客户端会拒绝协议4，避免旧文字锚点解析器误读新数据。所有参与同步的设备应先升级；不要新旧版本交替同步。
- 全量备份存在结构化印记历史时使用版本9（即使该印记随后已擦除）；只有旧文字印记时仍为8，无印记时为7。ZIP、流式快照、原生目录读写均支持9，并保持容器校验和、损坏数据拒绝恢复的边界。
- 为延续容器布局，内部 payloadEntry 文件名仍是 snapshot-v7.json；格式版本以 manifest/container 为准，不按文件名判断。
- 知识库协议和知识备份 envelope 不变；无需本轮部署 Firestore 规则。10月11日知识库样式规则的既有生产部署保持不变。
