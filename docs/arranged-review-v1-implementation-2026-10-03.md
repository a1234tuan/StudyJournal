# 安排复习 V1：实现与验收记录

日期：2026-10-03。指导方案：`arranged-review-v1-frozen-plan-2026-10-03.md`。本文覆盖源码实现与隔离自动化验证，不代表安装包发布、生产账号验证或用户人工验收。

## 使用入口

- 普通复习 → 待复习看板：搜索标题/标签，按科目、知识库专题/节点筛选；点单卡或勾选部分先复习。未选卡片仍到期，所选完成后可继续剩余。
- 知识库大纲/导图 → 安排复习：在当前知识库树中选择节点/日志，默认包含后代节点，可跨专题选择、排除个别日志；按原树顺序合并并去重，创建固定名单。
- 复习 → 已安排：进入本轮清单，点击条目直接进入原复习卡。四档自评保存成功后返回清单打勾；“忘记了”同样表示本条已评价，不代表掌握。顺序不变、不自动移除完成项。
- 完成项可回看、显式撤销评分。允许继续中断轮次、提前结束、删除、再练一轮/薄弱项再练。结束不丢部分结果，删除不删除正式助教历史。
- 重点块评论下方的“学习助教 · 分析本卡”保存并处理当前卡选中的反馈，展示状态、错误/重试、结果和进入训练入口。无重点块的日志仍使用原 AI 问答。

## 实现边界

### 数据与调度

数据库 schema 从 27 升至 28，增加三个表：

- `arrangedReviews`：固定名单、标题、来源摘要及结束/删除时间。
- `arrangedReviewEvents`：不可变评价事件，记录日志版本、四档评分或撤销，以及被替代事件的 parents。
- `arrangedReviewDrafts`：本机评论草稿，按轮次/日志或普通复习发生实例隔离，不进入云同步/完整备份。

独立评分不调用普通 `rateRecordReview`，不写 `recordReviews`、`recordReviewLogs`、`recordReviewDayStats`，不加入长期复习，不修改 FSRS 或普通下次复习时间。四档自评不是正式掌握证据。创建和评分事务检查日志可用性、内容版本、轮次状态及父事件；变更与普通云同步 mutation epoch 同事务提交。

同条日志的多个并发评分保留为独立 head；看板显示评价冲突，用户选择后写入引用全部 head 的新事件，不依赖时钟丢弃另一设备的评分。恢复前校验身份、时间、成员、父事件来源和环；拓扑校验采用线性迭代，覆盖 12000 条历史。

### 单卡助教

复用正式 feedback、interpretation、analysis queue、blueprint、task、outcome 和 delayed verification 体系，不另建一套训练模型。反馈 identity 含轮次/发生实例、重点块版本、评论、分析选择，避免分析后评分重复落库；轮次来源保存 ID 和标题。

仅显式点击触发分析；评分不再自动解释反馈。单卡深度规划限制到提交的 feedback IDs，续接批次限制到其冻结输入；同块同版本已有未结束任务时不覆盖/不重复创建，新反馈保留。关闭页面或重启不会自动继续付费请求；待续分析有明确继续入口。训练任务和结果仍按原正式事实同步，不改普通间隔调度。

### 界面与导航

原 ReviewPage 接收独立上下文，保留正文、重点块、编辑、AI 问答、批注和评分视觉；普通与独立队列互不混用。轮次/卡片位置存在本机 localStorage，列表进度来自数据库事件。手机返回从卡到看板、从看板到轮次列表；编辑和训练返回原卡。

模式切换、返回看板、独立评分及进入单卡助教接入现有批注导航保护：未完成交互或保存失败阻止离开，不能直接卸载丢草稿。桌面、390px 手机和 320px/150% 字号均检查截图；修正了选择器标题挤成竖排、原生 dialog 的窄屏边距、暗色主按钮对比、手机批注按钮遮挡更多菜单。截图等待页面过渡结束，不以重叠动画帧作为静态视觉结果。

### 同步与备份

普通云同步增加 `arranged-review`、`arranged-review-event` 两类实体，复用原同步租约、冲突及完整性处理；知识库同步协议不变。名单引用普通日志 ID，不复制内容。轮次删除保留 tombstone，助教事实不级联删除。

普通 ZIP、可流式快照、原生流式导入和目录仓库恢复携带两个正式数组。旧备份两个字段均缺失表示“不处理本机轮次”；显式空数组表示恢复为空；只存在其中一个字段拒绝恢复。云同步应用保留本机草稿，版本不匹配时不把旧评论套在新内容上。

**混合版本限制**：普通同步协议号仍为 2，知识库协议仍为 1；实体集合有扩展。旧客户端不理解新实体，不能安全参与这些轮次的同步，也没有协议升级阻断保护。启用本轮云同步前必须停止旧端同步、升级所有参与设备，并保留完整备份；本轮不宣称新旧版本混合同步兼容。真实账号多设备验收与安装升级留待单独授权。

## 人工验收建议

1. 在知识库选择分散节点的日志（包含未加入长期复习的日志），创建一轮；任意点卡评分，确认返回原位置打勾。
2. 中途退出/重启后从“复习 → 已安排”继续；普通复习依旧能独立进入，未选卡片仍待复习。
3. 对重点块填评论、点击单卡助教，查看结果并进入训练；返回后仍是原卡。检查评分不额外调用模型。
4. 检查手机明暗主题、大字布局、编辑/批注/返回操作，以及提前结束、撤销评分、薄弱项再练。

未执行安装 APK/EXE、生产部署、真实账号写入或付费供应商调用。本轮改动未自动 Git 提交；既有安装不受本轮源码修改影响。浏览器与截图覆盖自动化桌面 Chromium 和窄屏视口，不代替实体 Android 设备验收；启用云同步前所有参与设备必须升级到包含新实体的版本。
