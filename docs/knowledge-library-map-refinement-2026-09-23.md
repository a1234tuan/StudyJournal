# 知识库导图、大纲与详情精细化验收

日期：2026-09-23。用户授权直接实施；源码与本地自动化验证完成，等待用户验收。未安装用户应用，未提交或推送本轮修改。

## 实施范围

- 导图不再使用大纲的纵向遍历坐标排版。专题作为展示中心，顶层分支按子树高度分配到左右两侧，父节点与子树居中对齐，分支内部继续向外延伸。布局中心不是新增的持久化节点。
- 节点按标题长度估算宽高，长标题换行；中心、一级分支、普通节点使用不同视觉重量。曲线连接实际节点边缘，分支色保持克制。叶节点不显示无效折叠按钮。
- 移除六点拖动把手。桌面直接拖节点主体；触屏长按 350ms 后拖分支。预览跟随指针，合法父节点、前后插入位置、非法后代落点都有反馈。Escape、pointercancel 或无效落点不提交写入。
- 支持同级前后排序、改变父节点、移动到专题中心。位置写入沿用原有 position/orderKey 命令与事务协议，不改同步格式或 schema；中心不允许作为可移动实体。
- 节点单击直接打开详情，双击或 F2 原位编辑。为区分双击，鼠标单击有 220ms 判别延迟；触屏轻触直接打开。圆形加减控件只折叠分支，不触发详情或拖拽。
- 详情以日志为主体：标题、文档图标、打开箭头、次要日期／学科，备注及节点说明按需展开。引用操作收纳到每行的省略号菜单，操作字体小于日志标题，一次只展开一个菜单。
- 桌面详情为右栏，窄屏为底部面板，最大占工作区 52%；选中节点保持在剩余可见区。删除旧的“详情”按钮，详情打开时不重复显示底栏的“添加日志”。
- 大纲改为节点与日志的混合虚拟列表：直属日志先于子节点、不同字号字重与图标、分支整体折叠、日志直接打开。保留 Enter 新建同级、Tab 新建子节点、Shift+Tab 提升层级、F2 编辑；箭头导航覆盖混合行。
- 导图视角与分支侧向属于导航状态，不写入知识事实。首次窄屏显示最低 85% 的可读比例；大型导图允许横向平移，“查看全貌”才缩小到完整树。选中全貌中的节点时恢复最低 85% 阅读比例。不是自由坐标白板。
