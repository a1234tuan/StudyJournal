日期：2026-10-08。状态：用户授权后已实施并完成定向验证，等待视觉验收。实施结果、截图与未覆盖边界见 `docs/content-first-ui-implementation-2026-10-08.md`；下文保留设计阶段合同。

本文修订 2026-10-07 接入方案中的空间参数、知识库侧览和导图表达；冲突时以本文为准。V2 HTML 是正式落地的视觉基线，不是功能规格；真实能力和导航边界按本文约束。此前工作已提交为 `9cb4c95`，未推送；`output/editor-review-ux-2026-10-04/` 仍为未跟踪历史产物，不纳入此次变更。

## 1. 核对结论：保留产品能力，而不是复制样稿

- **关联日志原地预览已经存在。** 正式知识库的大纲关联项、节点说明中的日志条目进入右侧只读预览；预览提供“返回节点说明”和“打开完整日志”。不应把样稿的跳转方式当成新标准。
- **正式导图不是样稿里的静态 SVG。** 现有节点显示日志数量，点击数量打开关联列表；没有为每篇关联日志画一条虚线。样稿虚线应去除，不引入生产。
- **导图已有应用内全屏和适应画布两个不同动作。** 普通模式已使用剩余工作区；全屏隐藏导航，退出保留缩放与选中状态。不能为了统一页面宽度，把正式导图缩成样稿里的小画布。
- **日志资料库的列表旁预览是新导航能力。** 它与知识库已有侧览不同，需要接入历史、列表滚动、搜索和编辑返回链路；不是换 CSS 就能完成。
- 本轮确认的是代码行为与设计差异，不是新布局已经通过运行验证。截图只能说明样稿问题，不能据此断言正式节点同样过大。

## 2. 哪些去除，哪些必须保留

### 生产不带入的样稿元素

- 顶部绿色演示栏、绿色外框、版本标签、“功能对应 / 页头对比 / 减少动效”等演示控制。去除演示入口不意味着去掉系统减少动效支持。
- “右侧预览 · 待接入布局”“已保存（示例）”、假日期、假数量、假收藏、假专题归属、固定六条日志，以及展示用成功提示。保存和同步状态只能来自真实状态源。
- 样稿正文的“用自己的话再说一次”“留给下次的问题”等示例内容：不得注入用户日志或变成默认模板。
- 为凑构图绘制的虚线关联、示例文档卡片、装饰性大图、大面积空白和反复解释当前页面的段落。
- 只有提示弹窗、没有业务动作的假按钮。样稿正文底部 AI / 复习 / 收藏组合不得直接变成正式详情页的新功能。

### 必须保留的真实能力

- 页面身份、当前日期/学科/筛选、真实标题、加载/空/错误状态、选择态、编辑与保存反馈、明确的返回路径。删除大标题不等于删除这些信息：以紧凑页栏和上下文标签承接。
- 日志各分支既有日期、学科、日历、搜索、渐进加载和批量入口；今日页计划、新建、模板、复习、收藏、同步以及已有标题编辑。不能因为样稿没画就删掉。
- 知识库节点增删改移、折叠、键盘操作、拖拽、缩放、适应画布、全屏、关联备注、移除引用、资料源状态及编辑离开保护。
- 局部图标、轻分隔、少量学科/状态色可保留，但色彩不能成为唯一状态提示，装饰不能抢占正文位置。

### 必须按入口保留的语义

- 日志列表 AI 入口目前按日期传入；已有单条 Coach 入口按日志范围传入；正式完整日志页目前没有样稿所画的同组 AI 按钮。不能偷偷统一为单条 AI。
- 知识库关联列表/大纲打开侧览；知识库搜索的日志结果目前打开完整日志。第一批不强行改成同一种行为。
- 日志列表当前日期优先、再按更新时间排序，不得直接贴上“最近更新”标签；不在视觉改造中增加尚不存在的排序/筛选。
- “移除引用”不等于“删除日志”；不可用或已删除的来源须诚实显示，不得伪装为空内容或悄悄丢掉关联。

## 3. 日志页：缩小索引，不缩小阅读区

### 修正上一版宽度建议

撤回把整个三栏工作区限制为 1104px、正文一律限制为 560px 的建议。**阅读面板宽度与文字行宽是两件事。** 三栏工作区使用可用宽度；左侧索引紧凑，右侧正文获得余量；仅普通文字限制舒适行宽，图片、表格、代码、公式可使用面板更大宽度，必要时内部横向滚动。

建议初始参数（待真实内容验证，不是已经通过的尺寸）：

- 保留现有导航及折叠机制，不强行新增一套侧栏宽度规则。日志索引默认约 260px，可在 240–280px 内适配；不要让它随大窗口无限变宽。
- 阅读面板目标至少 600px；普通段落行宽约 600–720px，面板内边距约 20–28px。面板可以更宽，正文不必铺满。
- 按可用工作区而非设备名称决定分栏：扣除索引、分隔线和阅读区后不足时，切为单阅读面板并提供“返回列表”；不挤出一个难以阅读的小侧窗，不强制隐藏全局导航。
- 1440px 宽、导航占 220px、左右总留白 32px 的示意预算：剩余 1188px，索引 260px 与分隔 1px 后，阅读面板约 927px。此为设计计算，不是当前 APP 的实测。

### 把正文向上提，而不是压小字体

- 去掉演示栏、大页头说明和预览身份的重复说明。页面身份、视图与搜索/筛选入口集中到紧凑工具栏，默认一行；长标签和大字号允许有序换行，不设置截断工具栏的死高度。
- 不默认平铺全部学科标签。使用现有学科筛选的紧凑选择入口，选中后显示当前条件及清除操作；更多条件收纳到可键盘操作的面板。仅在对应分支有该能力时呈现，不扩展筛选语义。
- 阅读区只保留一条紧凑工具栏（目标 40–44px）、必要元信息、真实标题和正文；标题前空隙约 12–20px。移除样稿额外 33px 顶部间隔，不删真实标题，也不把所有元信息重复摆两遍。
- 在 1440×900、默认字号、短标题的检查样本中，正文起点目标距工作区顶部不超过约 160px；长标题、大字号可自然增高，不为了达标裁切。
- 列表条目目标约 60–76px，标题最多展示两行，辅以一行日期/学科；附件和收藏采用小标识。字号和触控热区不缩水，长标题有完整可访问名称；不同时堆叠摘要、标签、按钮和统计。
- 常用动作保持可发现；低频动作可收纳，但键盘聚焦和触屏必须能访问，不能只有鼠标悬浮才可操作。

### 侧览范围

第一轮仅对普通“全部日志”列表接入只读侧览，保留列表筛选、已加载数量、选中项与滚动位置；日历、日期/学科下钻、搜索、收藏来源仍走原链路。进入完整阅读/编辑后返回同一来源，关闭侧览不清筛选、不重载第一页。以后扩大范围必须单独列出相应返回合同。

## 4. 知识库：画布为主，详情按需

### 画布不套阅读页的窄版模板

保留现有 flex 剩余空间布局与应用内全屏，减少外部页头/留白，而不是给导图固定一个更高的卡片。没有打开详情时，导图占满主题工作区；打开详情后才让出阅读空间。既有视图/专题标题/必要动作保留；长操作提示降为首次或帮助提示，不能覆盖选中节点。

移动导航折叠入口到侧栏边缘时，复用当前知识库专用状态；折叠后仍有明确的展开入口、悬浮提示、可见键盘焦点及足够热区。不改变其他页面的导航状态。

侧窗打开、窗口缩放、侧栏折叠不自动“适应全部”：那会让图突然缩小。保留当前相机/缩放与选择锚点；如需露出被遮挡节点，优先最小平移，显式点击“适应画布”才计算全图。适应画布与全屏始终保留独立语义。

### 节点先测量，再决定压缩程度

正式普通节点宽度由内容计算，当前约 108–240px；中心节点约 176–264px，基础最小高度分别 44/60px。短标题且有关联时的预留宽度为 86px，无关联为 28px，是值得检查的空间来源；不能据样稿直接把所有节点减半。

第一优先消除无信息留白，保留可读字号、数量按钮、折叠热区与长标题换行。节点仍按文字/徽标实测自适应，禁止全部固定同宽。布局横间距 64px、子树内纵间距 20px 不急于一并压缩，先确认大图和长标题确有收益。

若修改尺寸，必须同步几何布局、连线路径、拖拽预览/命中区、键盘邻接、聚焦与缩放边界；不能只用 CSS 缩小卡片。该项单独列为中风险阶段，不伪装成纯样式调整。

### 不用虚线表示每篇关联日志

建议正式版继续采用“结构实线 + 日志图标/数量 + 关联列表”：

- 结构线只表达节点父子关系；日志不是树的子节点，不为其额外拉线。
- 无引用时不制造空的文档图形；一个引用仍走一致的数量/详情入口；多个引用点击数量进入列表，按真实引用顺序展示标题与必要元信息。
- 同一日志在多个节点被引用时，各节点各自计数，不绘制跨画布连线，不假装它有多个内容副本。
- 备注展开、编辑备注、移除引用保留；关联列表可滚动，数量多也不无限放大节点或抢占画布。

这样 1、10、100 条引用的图形规则一致。跨节点关系图、临时关系连线均不在本轮范围。

## 5. 点击关联日志：默认原地读，需要时再打开完整页

建议保留现有路径：**节点数量 → 节点关联列表 → 日志只读预览 → 明确点击“打开完整日志”**。不要自动跳全屏，也不要弹一个只能读两行的浮动提示框。

- 预览替换右侧节点说明，不在其右边再叠第四栏。关闭预览回到原节点说明；保留导图选择、缩放、位置和预览阅读位置。
- 当前预览默认 420px、可调 360–560px；有键盘分隔条和富文本只读渲染。宽屏可试默认 480px，范围仍先保持 360–560px，减少导航持久化协议改动。导图预览是快速核对，不应照搬日志页主阅读面板的最小宽度。
- 仅当工作区足以同时给画布约 600px 与阅读侧窗 480px 时采用该宽屏默认；空间不足保留现有自适应。用户已保存的有效宽度优先，不擅自覆盖。最终默认值须用真实长文、公式、图片验证后敲定。
- 现有工作区不足 720px 时，预览改为底部 75% 高的阅读层，并非右侧硬挤窄栏。第一批保留此机制及关闭/返回行为，不连带改成另一套移动导航。
- 现有知识库返回事件依次处理弹窗/编辑/忙碌保护、日志预览、节点说明、全屏、选择、专题。UI 返回、Escape、浏览器/设备返回按各自既有合同核对；不能简单规定“所有返回都退首页”。
- 知识库搜索结果仍按原行为进入完整日志。未来若统一为侧览，要额外定义搜索高亮、搜索结果滚动与返回层级，不能顺手修改。

## 6. 分阶段接入及一次性阶段门槛

### A：去除演示成分，整理页头和空间

逐项建立可见控件到真实回调/数据的映射；演示文案只从样稿迁移清单剔除，不删除用户实际写过的同名文字。Today/Journal 使用局部样式或显式密度变体，禁止全局更改共享 PageHeader/RecordCard 默认行为。导图不受阅读页 max-width 影响。收敛后验证长标题、多学科、空状态、暗色、窄屏和动作入口。

### B：优化知识库已有侧栏与预览

移动折叠入口、优化宽屏预览默认值与顶部留白；复用现有读取、resize、返回与 scroll 保存。集中执行相关组件/导航用例及已有导图浏览器用例中的宽度、来源返回、折叠/全屏状态保持。未改的拖拽算法不为此重写。

### C：接入日志列表侧览

仅在全部日志分支新增只读侧览，明确状态及历史序列化、列表独立滚动、渐进加载触发点、快速切换过期回调保护。完整编辑仍复用现有页面与未保存保护。按“列表 → 侧览 → 完整页/编辑 → 返回侧览 → 关闭回列表”集中验证；搜索/日历旧入口做小范围不变性回归。

### D：有测量依据才压缩节点

对真实布局构造短/长标题、1/10/100/1000 引用、多级树、不同字号；只有确认当前留白问题才调整尺寸预留。集中验证布局/命中/拖放/折叠/缩放与键盘邻接；不改则记录跳过，不制造一次无必要的重构。

### E：最终集成验收

每阶段先收敛改动，再跑该阶段最小相关测试集合；失败只修定位到的范围、复测失败项及其直接影响项。最终跑受影响用例并集、TypeScript 与一次生产构建，不因每次 CSS 调整重复全量或打包。若后续修改影响编译/产物，已有构建证据失效，需要相应补验，不能以少测试为由跳过。

桌面浏览器几何通过不等于 Electron/Android 已通过。最终在获准的隔离宿主检查返回、窗口缩放、输入焦点及触控；不覆盖现有安装、不使用真实云账号、不调用付费 AI。未经宿主检查的部分明确列为待验收。

## 7. 不能只看截图的验收清单

- **几何：** 1920、1440、1280、1024、768、390、320px 宽；至少覆盖 720px 工作区边界与 920px 导航边界两侧。默认/大字号、深浅主题、超长标题/标签、不间断文本、图片/公式/代码均不覆盖按钮或造成页面整体横向滚动。44px 级触控目标与可见焦点不因压缩丢失。
- **空间：** 记录工作区/索引/阅读面板实际宽度、正文起点和导图有效区域，不只凭“好像更宽”。宽屏正文优先得到空间；窄屏按合同切换，不靠缩小字体掩盖不足。
- **交互：** 鼠标、键盘、触控；打开/关闭筛选、切记录、调整侧窗、节点数量、关联备注、全屏/适应画布均走真实回调；隐藏层不得拦截当前页面。
- **对称流转：** 分别从全部日志、搜索、日期/学科、收藏、知识引用、知识搜索进入，按来源退出。验证浏览器前进/后退、Escape、设备返回；有编辑草稿时先保护内容。
- **状态：** 加载更多后打开/返回仍停留原项；快速点击 A/B 不显示 A 的迟到内容；删除/同步失效来源显示不可用；窗口变窄/放大、折叠侧栏不丢选中与阅读位置。
- **纯展示边界：** 选择、浏览、筛选、展开、关闭不得新增业务写入、修改 updatedAt、创建复习日志或触发 AI；允许既有设备本地导航/宽度/滚动状态持久化。结构操作只维持原来对应写入。
- **图形：** 引用数量增大不挤掉文字或吞掉拖拽；连线仍接到节点边界，缩放/布局更新后命中与外观一致，底层导图不响应侧窗内编辑/滚动快捷键。

## 8. 开工前冻结的决定与可留到实测的点

现在应冻结：不迁移演示数据；内容优先；不绘制每条日志的虚线；知识引用默认保留原地预览；完整编辑仍保留；日志侧览先限定全部日志；不改变来源动作语义；不改数据表、同步、备份、调度和 AI 范围。

留到隔离候选实测：索引最终宽度、行高、正文行宽、宽屏知识预览默认值、是否确需改节点几何。这些只能在本文区间/行为约束内微调；若要增加筛选、统一搜索侧览或改变移动导航，应重新确认范围，不在验收前临时补功能。
