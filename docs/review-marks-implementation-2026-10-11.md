# 永久复习印记实施与验收记录

日期：2026-10-11。授权依据：用户要求按阶段实现并自行验证，全部完成后统一验收。
范围合同：docs/review-marks-scope-and-contract-2026-10-11.md。

## 实施结果

### 第一阶段：永久数据、同步与备份
- 新增 reviewMarks 模块及 Dexie schema 29 / reviewMarkEvents 表。
- 每个印记单独编号，新增/改样式/擦除/撤销均写不可变事件。使用事务校验日志版本、当前分支、恢复状态及云修改 epoch，过期操作明确拒绝。
- 不同印记可合并，同一印记的离线编辑保留分支；擦除与修改并发时隐藏印记，并在工具中提示用户选择保留版本或确认擦除。
- 评分、重置、移出复习及重新加入均不擦除印记；永久删除原日志才清理其历史。
- 普通云实体 review-mark-event、普通/流式快照、ZIP、原生 ZIP、目录仓库、云恢复均已接入。
- 普通云协议由 2 升为 3；新客户端在事务锁内接管旧协议，既有旧客户端后续无法获取协议3的写锁。未来未知协议在读取同步状态时即拒绝，不进行覆盖。
- 完整备份在存在印记历史时使用版本8及受校验容器，旧客户端拒绝该版本而非静默漏项。无印记仍是版本7。知识库 wire/envelope 和先前已部署规则不变。
- 旧备份缺少印记字段保留本地数据；版本8缺字段、坏父链、重复身份等拒绝恢复；显式空数组表示替换为空。

### 第二阶段：普通复习中的交互
- 复习局部栏新增书签形“印记”入口，手机使用小图标；与临时“批注”工具互斥，不增加默认常驻工具栏。
- 开启后使用底部工具面板，暂时收起评分按钮，关闭即恢复评分。工具不推动原文，窄屏限制高度并可滚动，留出正文阅读空间。
- 四色高亮、下划线、文本范围框选、段落边标；预设“重点 / 易混 / 已熟悉”提示。
- 同一段内选字添加印记；“重点列表”中修改样式、擦除、重新定位及确认并发版本。
- 提供撤销按钮，工具开启时 Ctrl/Cmd+Z 只撤销印记，避免误撤回评分；连续撤销有因果保护。
- 上一处/下一处按正文顺序跳转，重点列表保留完整上下文，不自动折叠正文或把提示当成调度事实。
- 锚点使用文本、上下文而非像素坐标，跨屏幕宽度和字体缩放重新测量。内容变动、重复/歧义段落不绘制，保留待定位条目。
- 只在普通日志间隔复习渲染。原日志编辑/预览、知识库、AI输入和独立已安排轮次不加载印记界面。
- 保存过程中复用复习导航等待机制；写入失败显示错误，不绘制“假保存”的印记，可重试。

## 用户验收入口与边界
1. 普通复习进入一篇日志 → “印记” → 在同一段内选字 → 选择样式/颜色并标记。
2. 关闭工具、评分、离开再进入，确认印记仍在；进入原日志编辑/完整浏览时应看不到印记。
3. 打开重点列表，修改、擦除、撤销和重定位；确认上一处/下一处顺着正文跳转。
4. Android实体设备重点检查长按选字、选字手柄与底部工具的协调；非文本图片圈画、自由手绘和跨段圈画本轮未实现。
5. 云同步与备份不是本机临时能力：已接入并通过模拟双设备及各归档通道测试；真实双设备须先都升级客户端，再验收同步/擦除一致性。不要让旧客户端与新版混用。
6. 安装在手机/Windows上的应用不会因源码修改自动升级，本轮未产生安装包。用户视觉与真机验收仍待进行。
