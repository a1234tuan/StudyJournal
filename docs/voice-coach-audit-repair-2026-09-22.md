# 语音复述与学习助教审计修复记录

日期：2026-09-22

本记录对应外部《语音复述与学习助教模块缺陷审计报告》。报告中的 P0/P1 条目均按当前 \`main\` 代码独立核对；P2 条目不在本次修复范围内。

## 已确认并修复

- P0-01：自由主题会话在创建时清除旧日志、任务和范围引用；提示构建也以持久化会话的来源边界为准，因此旧日志不会进入自由主题请求。
- P0-02：学习助教的所有 Hooks 在条件空状态返回前执行；来源记录、任务或蓝图消失时显示不可用状态，并保留未提交答案供复制。
- P1-01：提示、跳过以外的异步操作不再清空答案、图片和语音转写确认状态；提交答案后仍按原语义清理草稿。
- P1-02：按住讲话记录按压生命周期；启动录音期间松手、取消指针或失去指针捕获都会取消启动，音频焦点获取完成后还会再次校验取消信号。
- P1-03：暂停并离开后，开始页显示本机可恢复检查点；恢复先重建服务并保持暂停，不自动打开麦克风，需用户明确点击继续通话。
- P1-04：超出模型上下文的决策块保留在待分析队列并显示原因；同批次其余合规块仍可分析。服务层仍拒绝超限输入，不做静默截断。
- P1-05：本机历史摘要支持保存前编辑和容量计数；超限时禁止提交并明确提示，不自动截断完整通话；普通写入失败通过统一 UI 错误提示展示，保存使用会话级幂等 ID。

## 明确未处理

- 未调用真实 AI、付费 Provider、真实麦克风或生产 Firebase；Android/Desktop 安装包和生产规则未部署。
