# StudyJournal 视觉样稿 V2：功能对齐，内容优先

日期：2026-10-07。V2 取代上一版首页大插画/继续上次主卡。只修改独立 HTML 样稿，不修改正式 APP，不表示已接入产品。

用 Chrome / Edge 打开本目录 index.html；无需启动服务或安装依赖。如果编辑器显示源码，请右键该文件选择“打开方式 → Chrome”。顶部“功能对应”可直接查看本轮的功能边界。

## 三项修订

### 1. 与当前功能一一对应，不再混入未实现设想

- 桌面恢复今天 / 日志 / 复习 / 知识库 / 更多；AI 问答仍在更多，不擅自新增一级入口。窄屏维持今天 / 日志 / 新建 / 复习 / 更多。
- 今天保留新建学科记录与模板选择、今日计划、收藏夹、云同步、当天记录、复习状态和目标日期。样稿只显示 3 条当天日志，不冒充最近打开历史。
- 删除“继续上次”和首页专题推荐；这是前版的新增产品设想，并非现有 TodayPage 已有能力。
- 日志保留全部日志 / 按日期、学科筛选、全局搜索、知识库入口。排序继续记录日期优先，其次修改时间，只把误导的“最近更新”显示改成“记录日期优先”。不加入任意排序/新集合内搜索。
- 日志的 AI 问答继续按照 onAskAi(record.date) 表示日期范围，不再写“针对这条提问”。复习、收藏和编辑仍对应现有动作。
- 知识库用词保持大纲 / 导图 / 安排复习 / 查找 / 更多；返回知识库列表，不跳到日志列表。多库管理仍有入口。
- 现有入口不等于样稿已接入：新建、复习、收藏、同步、设置等按钮只说明去向，不操作真实数据。按日期等子流程保留入口但本轮没有重绘完整交互。专题导图只是示意，不支持正式节点编辑。

依据：src/pages/TodayPage.tsx、src/pages/JournalPage.tsx、src/components/RecordCard.tsx、src/pages/MorePage.tsx、src/features/knowledgeLibrary/KnowledgeLibraryPage.tsx。

### 2. 用实际宽度上限，而不是再缩小字号

- 首页整体最大 960px，包括侧边 224px 的复习/目标信息和 24px 间隔；主日志列最大 712px。
- 资料浏览工作区最大 1104px；侧栏列表 296px；阅读正文最大 560px。关闭侧览后，列表也不会无限拉宽，仍最大 712px；展开阅读正文最大 620px。
- Chrome 在 1280、1440、1920px 窗口下测得首页条目均 712px、侧览列表均 296px、正文均 560px。大屏增加外侧留白，不拉长文字行。
- 390px 下首页条目 354px、正文 350px；阅读时列表隐藏，关闭后回列表。上述状态没有整页横向溢出。
- 这些是已在样稿测量的尺寸，不是正式 APP 已实现，也不是未来不可调整的常数。正式落地还要验证用户字号、缩放、公式/图片与长标题。

### 3. 视觉重点回归内容

- 撤掉首页大插画主卡、整块紫色复习宣传卡、专题推荐和装饰口号。
- 首屏直接看到当天记录标题、摘要与学科/日期；复习状态退到侧边，不压过日志。
- 图标用于识别入口与操作，少量颜色用于选中与层级。没有居中的装饰画，也不自动插画/重写用户日志。
- 去掉阅读区人工加入的向量装饰示意图；保留手工编写的示例正文与问题段落。正式应用中的真实图片、公式和图表当然继续呈现，它们是内容，不是要被删除的装饰。
- 专题导图本身是有用的结构信息，继续占据工作区；删掉导图周边的装饰曲线与色点。

## 接入判断：能接，但不能直接套 HTML

现有回调/数据可复用的部分：页面名称、列表数据、学科筛选、新建/模板、计划/收藏、复习入口、知识库大纲/导图等。样式层可逐步落到现有组件。

仍需工程实现的部分：日志侧览、列表和正文独立滚动、关闭恢复来源、导航边缘折叠，以及相应窄屏路由退化。必须接入现有草稿/批注离开守卫，不能绕过保护，也不能同时创建两个可写编辑器。涉及 TodayPage 条目菜单位置变化，也需要键盘/触屏验证。

这是明确的“复用现有能力 + 少量导航交互改造”，不是重写数据库或新增一套学习业务。UI 缩窄不应修改记录、复习事实、同步协议或备份边界。

## 本轮校验

- 修正样稿插入位置问题后，最终浏览器页面运行错误 0；没有调用外部服务。一次自动化检查使用了不准确的 label 定位而超时，改用明确的已有控件 ID 后完成剩余定向检查，没有运行产品全量测试。
- 核对桌面/窄屏导航、新建学科变化、功能对应说明、更多中的 AI、日期排序、数学筛选、关闭保留条件与列表限宽、搜索示例开文、知识库列表/专题/返回、窄屏单栏阅读与回退。
- 1280 / 1440 / 1920 / 390px 的布局测量见上文；截图仅为模拟数据的浏览器布局证据，不等于原生客户端或全量业务验收。
- 未构建产品、未打包、未写真实账户/日志、未提交或推送。
